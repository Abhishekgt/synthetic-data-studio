Overview

Synthetic Data Studio is an internal EY tool to create metadata-aware relational synthetic data for SAP migration projects. It preserves referential integrity across datasets and enforces mapping to SAP keys.

Architecture

Client-side prototype demonstrates the UX and client behaviors: dataset import, metadata mapping, relationship management, generation settings, preview, validation and export. Production systems would implement secure generation services and observability.

Metadata Enrichment

Enrichment suggests generators based on source types and business meaning. Confidence scores indicate heuristic quality.

Relationship Preservation

The Relationship Manager ensures referential integrity: parent keys are synthesized and mapped consistently into child datasets. Cross-dataset key mapping repository stores canonical synthetic keys.

Generation Pipeline

  1. Ingest source files, infer schema
  2. Enrich metadata and assign generators
  3. Validate schema and relationships
  4. Generate synthetic data respecting key maps and cardinality
  5. Export and deliver artifacts

Supported SAP Objects

Common fields and examples supported: KUNNR (Customer), VBELN (Sales Order), MATNR (Material), LAND1 (Country), ERDAT (Created Date), NAME1 (Name).

API Guide

This prototype includes "Export as REST" button which would in production provide endpoints to request generation and fetch results. See architectural notes for auth and rate limiting.
